プライバシーポリシー

施行日：2026-10-26

このページは翻訳です。繁体字中国語版と内容が異なる場合は繁体字中国語版が優先します。ただし、お住まいの地域の法令に別段の定めがある場合を除きます。

概要：お客様のコードとリポジトリの内容はお客様のパソコンにのみ保存され、アップロードされることはありません。当社が取得するのは、アカウント、ライセンス、決済、障害の調査に必要な最小限の情報だけで、個人情報を販売することはありません。ウェブサイトは「サインイン」をクリックするまで Cookie を一切設定しません。

1. 適用範囲と個人情報取扱事業者

本ポリシーは、ADGitter のウェブサイト、ADGitter デスクトップアプリ、および関連するオンラインサービスにおける個人情報の取扱いについて説明するものです。

お客様の個人情報を取り扱う責任者は異想科技有限公司（Another Dream Technology Co., Ltd.）です。所在地：2F., No. 143, Anxiang Rd., Xindian Dist., New Taipei City 231, Taiwan (R.O.C.)、メール：support@anotherdream.tw

2. 取得する情報

ウェブサイト

ウェブサイトは GitHub Pages でホスティングしています。ページの配信と安全確保のため、GitHub は訪問者の IP アドレスなどの技術的な情報を記録します。ウェブサイトでは解析・広告・トラッキング用の Cookie を使用していません。

ウェブサイトのサインイン機能は Clerk が提供しています。「サインイン」をクリックした後にはじめて Clerk のサインイン機能が読み込まれ、Clerk がサインイン状態の維持に必要な Cookie を設定します。

リポジトリとコード

すべての Git 操作はお客様のパソコン上で実行されます。コード、コミット、リポジトリのデータが当社や第三者に送信されることはありません。

アカウント

コア機能の利用にアカウントは不要です。有料機能を使うにはサインインが必要で、サインインは Clerk が提供しています。当社はメールアドレス、表示名、アカウント ID を取得します。

購入

決済は販売者である Polar が処理します。クレジットカードなどの支払情報は Polar とその決済代行会社が直接取得し、当社がカード番号の全体を見ることはありません。当社が受け取るのは、メールアドレス、購入したプランまたはテーマ、チームプランのシート数、注文・サブスクリプション・返金の状況です。

ライセンスとデバイス

プランごとのデバイス数の上限を適用するため、本ソフトウェアはインストールごとにランダムなデバイス ID を生成します。当社はこの ID、プラン、デバイスの最終接続日時を記録します。この ID にハードウェアのシリアル番号や個人情報は含まれません。

無料トライアル

パソコン 1 台につき 1 回だけ無料トライアルを提供するため、本ソフトウェアは OS が提供するコンピューター識別子を読み取り、お客様のパソコン上で不可逆なハッシュ値に変換してから当社に送信します。当社が保存するのはこのハッシュ値とトライアルの開始日時だけで、そのパソコンでトライアルを利用済みかどうかの判定に用い、お客様を特定するためには使用しません。

チーム（Enterprise）

チームのメンバーと招待は Clerk の組織機能で管理しています。当社は、お客様が所属するチーム、役割、参加日時、シートの割当状況を保存します。チームの管理者は、メンバーの表示名、メールアドレス、役割、シートの状況を見ることができます。メンバーはチーム名と他のメンバーを見ることができます。

クラッシュレポート

お客様が同意した場合に限り、本ソフトウェアは Sentry を通じてクラッシュ・エラーレポートを送信します。レポートには、アプリのバージョン、OS、エラーコードとエラーメッセージ、ランダムに生成されたインストール ID が含まれます。この ID に氏名やメールアドレスは含まれませんが、同じインストールのレポートを結び付けられるため、匿名ではなく仮名化された情報です。送信前にメッセージ中のメールアドレスとファイルパスを削除し、コードや差分は含めません。

広告（無料版のみ）

無料版の初回起動時に、広告の表示とクラッシュレポートの送信に同意するかどうかを確認します。同意すると、ウィンドウ下部に Carbon Ads の広告が 1 つ表示されます。広告は隔離されたフレーム内で動作し、リポジトリにはアクセスできませんが、Carbon Ads はお客様の IP アドレスとブラウザ情報を受け取ります。同意しない場合、広告欄は空白のままです。有料プランでは第三者の広告コードを一切読み込みません。

サポートと苦情

メールやサポートチケットをお送りいただいた場合、当社はその内容と連絡先を受け取ります。

3. 利用目的と法的根拠

  • アカウント、ライセンス、有料機能、チームの提供：お客様との契約を履行するため。
  • 購入、返金、請求に関する対応：契約の履行と、会計・税務に関する法令の遵守のため。
  • トライアルの重複利用、不正、濫用の防止とセキュリティの確保：当社の正当な利益に基づきます。お客様は異議を述べることができます。
  • クラッシュレポートと無料版の広告：お客様の同意に基づきます。同意は本ソフトウェアの設定からいつでも撤回できます。
  • お問い合わせ、サポート依頼、苦情への対応：契約の履行、またはお客様に回答するという当社の正当な利益に基づきます。

当社は個人情報を販売せず、広告用のプロファイルを作成せず、お客様に法的またはそれに類する重大な影響を及ぼす自動化された意思決定を行いません。

4. 委託先と第三者

当社は、サービスの提供に必要な事業者にのみ情報を提供します。GitHub、Clerk、Fly.io、Sentry は当社の指示に従ってのみ取り扱います。Polar と Carbon Ads は、それぞれ自らのプライバシーポリシーに基づき、自らの責任でも情報を取り扱います。

  • GitHub：ウェブサイトのホスティング
  • Clerk：ウェブサイトとアプリのサインイン、チームのメンバーと招待
  • Polar：決済、税務、領収書、返金。販売者（merchant of record）として、自らの責任でも取引データを取り扱います。
  • Fly.io：当社の API サーバーのホスティング（米国）
  • Sentry：クラッシュレポート（同意がある場合）
  • Carbon Ads：無料版の広告（同意がある場合）

5. 外国への移転

当社は台湾にあり、上記の委託先は主に米国で情報を処理するため、お客様の情報はお住まいの国の外に移転されます。EU、英国その他移転に保護措置を求める地域からの情報については、EU 標準契約条項や EU-米国データプライバシーフレームワークの認証など、委託先が提供する保護措置に基づいて移転します。

6. Cookie

ウェブサイトでは解析・広告・トラッキング用の Cookie を使用していません。「サインイン」をクリックした後にのみ、Clerk がサインイン状態の維持に必要な Cookie を設定します。サインアウト後は、これらの Cookie がサインイン状態を表すことはありません。

7. 保存期間

  • アカウント、ライセンス、デバイス、チームの情報は、お客様がアカウントを削除するまで保存します。チームを離れた場合、そのチームのメンバー記録は削除されます。
  • トライアルの記録（コンピューター識別子のハッシュ値）は、当社が無料トライアルを提供している間、同じパソコンでのトライアルの重複利用を防ぐために保存します。
  • クラッシュレポートは、問題の調査に必要な期間に限り保存します。
  • 取引の記録は、会計・税務に関する法令が定める期間、主に Polar が保存します。
  • 苦情とサポートの記録は、後日の紛争に備え、対応完了から 3 年間保存します。

8. お客様の権利

お住まいの地域の法令に応じて、お客様は次のことができます。

  • 当社が保有するお客様の個人情報の開示を求め、その写しを受け取ること
  • 不正確な情報の訂正を求めること
  • 情報の削除を求めること
  • 取扱いの制限を求めること、または正当な利益に基づく取扱いに異議を述べること
  • 提供した情報を一般的な電子形式で受け取り、または他の事業者への移転を求めること（データポータビリティ）
  • 同意をいつでも撤回すること（撤回前の取扱いには影響しません）
  • お住まいの地域の個人情報保護当局（例：英国の ICO）に苦情を申し立てること

support@anotherdream.tw までご連絡ください。開示や写しの請求には 15 日以内、その他の請求には 30 日以内に回答します。お住まいの地域の法令がより短い期限を定めている場合は、その期限内に回答します。

アカウントと支払いの情報は有料サービスの提供に必要です。ご提供いただけない場合は有料機能を利用できませんが、アカウント不要の無料のコア機能は引き続き利用できます。

9. 個人情報の窓口

当社の個人情報と苦情に関する責任者は 林紘立（Lin Hung-Li）です。連絡先：support@anotherdream.tw。各地域の法令が求める個人情報・苦情の窓口（例：インドの苦情処理担当官、韓国の個人情報保護責任者）もこの責任者が担当します。

10. 子ども

当社のサービスは 13 歳未満（お住まいの地域の法令がより高い年齢を定めている場合はその年齢未満）の子どもを対象としておらず、子どもの個人情報を故意に取得することはありません。取得してしまったと思われる場合はお知らせください。削除します。

11. 本ポリシーの変更

当社は本ポリシーを変更することがあり、その場合は本ページの施行日を更新します。重要な変更は、事前にメールまたは本ソフトウェア内でお知らせします。
