隐私政策

生效日期：2026-10-26

本页为译文。如与繁体中文版有出入，以繁体中文版为准，但你所在地法律另有规定的除外。

要点摘要：你的代码与仓库内容只留在你的电脑上，永远不会上传。我们只收集提供账号、许可、付款与错误排查所需的最少信息，不出售任何个人信息。官网在你点击“登录”之前不设置任何 Cookie。

1. 适用范围与个人信息处理者

本政策说明 ADGitter 官网、ADGitter 桌面应用程序及相关在线服务如何处理你的个人信息。

负责处理你个人信息的是異想科技有限公司（Another Dream Technology Co., Ltd.），地址：231 新北市新店區安祥路143號2樓，邮箱：support@anotherdream.tw。

2. 我们收集的信息

官网

官网由 GitHub Pages 托管。为了传送网页与维护安全，GitHub 会记录访客的 IP 地址等技术性数据。官网没有使用分析、广告或跟踪 Cookie。

官网的登录功能由 Clerk 提供。你点击“登录”之后，官网才会从 Clerk 加载登录组件，Clerk 也才会设置保持登录状态所需的 Cookie。

仓库与代码

所有 Git 操作都在你的电脑上执行。你的代码、提交内容与仓库数据不会发送给我们或任何第三方。

账号

核心功能不需要账号。使用付费功能时需要登录，登录服务由 Clerk 提供。我们会取得你的邮箱、显示名称和账号标识符。

购买

付款由交易卖方 Polar 处理。你的银行卡等付款信息由 Polar 及其支付服务商直接收集，我们看不到完整的卡号。我们会收到你的邮箱、购买的方案或主题、团队方案的席位数、订单、订阅与退款状态。

许可与设备

为了执行各方案的设备数量限制，本软件会为每次安装生成一个随机的设备标识符。我们会记录这个标识符、你的方案和设备最后联网的时间。这个标识符不包含你的硬件序列号或个人信息。

免费试用

为了让每台电脑只能免费试用一次，本软件会读取操作系统提供的电脑标识符，先在你的电脑上做不可逆的哈希处理，再发送给我们。我们只保存这个哈希值和试用开始的时间，用来判断这台电脑是否试用过，不会用来识别你的身份。

团队（Enterprise）

团队成员与邀请由 Clerk 的组织功能管理。我们会保存你属于哪些团队、你的角色、加入时间，以及你是否占用席位。团队管理员可以看到成员的显示名称、邮箱、角色与席位状态。成员可以看到团队名称与其他成员。

错误报告

只有在你同意后，本软件才会通过 Sentry 发送崩溃与错误报告。报告包含应用版本、操作系统、错误代码和错误信息，以及一个随机生成的安装标识符。这个标识符不含你的姓名或邮箱，但能把同一个安装的报告关联起来，因此属于去标识化信息，而不是匿名信息。发送前会先移除错误信息中的邮箱和文件路径，也不会包含代码或差异内容。

广告（仅限免费版）

免费版首次启动时，会询问你是否同意显示广告与发送错误报告。同意后，窗口底部会从 Carbon Ads 加载一则广告。广告在隔离的框架中运行，无法访问你的仓库，但 Carbon Ads 会收到你的 IP 地址和浏览器信息。拒绝的话，广告位置会保持空白。付费方案不加载任何第三方广告代码。

支持与投诉

你发送邮件或提交支持工单时，我们会收到你提供的内容和联系方式。

3. 处理目的与法律依据

  • 提供账号、许可、付费功能与团队：为了履行我们与你之间的合同。
  • 处理购买、退款与账单问题：为了履行合同，以及遵守会计与税务法规。
  • 防止重复试用、欺诈与滥用，维护信息安全：基于我们的正当利益。你可以对此提出异议。
  • 错误报告与免费版广告：基于你的同意，你可以随时在本软件的设置中撤回。
  • 回复你的问题、支持请求与投诉：为了履行合同，或基于回应你的正当利益。

我们不出售个人信息，不用你的信息建立广告画像，也不会做出对你产生法律效果或重大影响的自动化决策。

4. 第三方服务

我们只把信息提供给提供服务所需的服务商。GitHub、Clerk、Fly.io 与 Sentry 只按我们的指示处理；Polar 与 Carbon Ads 也会以自己的身份处理数据，并适用它们自己的隐私政策：

  • GitHub：官网托管。
  • Clerk：官网与应用程序的账号登录，以及团队成员与邀请。
  • Polar：付款、税务、收据与退款，是交易卖方（merchant of record），也会以自己的身份处理交易数据。
  • Fly.io：托管我们的 API 服务器，位于美国。
  • Sentry：错误报告，需经你同意。
  • Carbon Ads：免费版广告，需经你同意。

5. 跨境传输

我们位于台湾，上述服务商主要在美国处理数据，所以你的信息会被传输到你所在国家或地区以外的地方。来自欧盟、英国或其他要求传输保障的地区的数据，我们依靠服务商提供的保障措施传输，例如欧盟标准合同条款，或服务商取得的欧盟－美国数据隐私框架认证。

6. Cookie

官网没有分析、广告或跟踪 Cookie。只有在你点击“登录”后，Clerk 才会设置保持登录状态所需的必要 Cookie；退出登录后，这些 Cookie 就不再代表任何登录状态。

7. 保存期限

  • 账号、许可、设备与团队数据会保存到你删除账号为止。你离开团队后，该团队的成员记录会被删除。
  • 试用记录（电脑标识符的哈希值）会保存到我们不再提供免费试用为止，用来防止同一台电脑重复试用。
  • 错误报告只保存到排查问题所需的期间。
  • 交易记录按法律规定的会计与税务期间保存，主要由 Polar 保存。
  • 投诉与支持记录保存到处理完毕后 3 年，以备后续争议。

8. 你的权利

依你所在地的法律，你可以：

  • 查阅我们保存的你的个人信息，并获取副本。
  • 更正不正确的信息。
  • 要求删除你的信息。
  • 要求限制处理，或对基于正当利益的处理提出异议。
  • 以常用的电子格式获取你提供的信息，或要求转移给其他服务商（数据可携带）。
  • 随时撤回你的同意，不影响撤回前的处理。
  • 向所在地的个人信息保护主管机关投诉（例如英国的 ICO）。

请发送邮件至 support@anotherdream.tw。查阅或获取副本的请求，我们会在 15 天内回复；其他请求在 30 天内回复。你所在地法律规定更短期限的，依其规定。

账号与付款信息是提供付费服务所必需的；不提供的话就无法使用付费功能，但仍可使用不需要账号的免费核心功能。

9. 个人信息保护联系人

我们的个人信息保护与投诉负责人是 林紘立，联系方式：support@anotherdream.tw。这位联系人也负责各地法律要求的个人信息与投诉窗口事务（例如印度的申诉专员、韩国的个人信息保护负责人）。

10. 儿童

我们的服务不是为 13 周岁以下的儿童设计的，也不会在知情的情况下收集儿童的个人信息；你所在地法律规定更高年龄的，依其规定。如果你认为我们收集了儿童的信息，请通知我们删除。

11. 政策变更

我们可能更新本政策，并更新本页的生效日期。重大变更会事先通过邮件或在本软件内通知你。

12. 联系我们

关于隐私的任何问题，请发送邮件至 support@anotherdream.tw。另见服务条款与经营者信息。
